Each role catalog links to the common screens. Screens with different layouts or actions by role remain separate, even when their routes match. Access-restriction images show operations the role cannot access.

The gallery covers pages, forms, dialogs and key states using representative data, rather than every SKU, input combination or mobile size. Empty lists, completed records and temporary-password states use isolated fixtures; other actions run through the UI. The 10 representative images in the gallery root remain available for the walkthrough.
